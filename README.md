# Pigeon Service – Stock Management System

A terminal-based Stock Management System developed using Java for the Programming Fundamentals (PRF) module. The application provides a menu-driven interface to manage suppliers, product categories, and stock items for Pigeon Service.

## Features

- **Change Credentials** – Update system login credentials.
- **Supplier Management** – Add, search, update, delete, and view supplier details.
- **Stock Management** – Manage product categories and stock items.
- **Category Management** – Organize products by category.
- **Supplier-wise Stock View** – View stock items associated with suppliers.
- **Price Ranking** – Display stock items ranked by price.
- **Console Interface** – Navigate the system through a terminal-based menu.
- **Loading Animation** – Display a simple loading animation during system operations.

## Technologies Used

- Java
- Java Scanner for user input
- Arrays for storing supplier and stock information
- Methods and control structures
- Command-Line Interface (CLI)

## Getting Started

### Prerequisites

- Java Development Kit (JDK) installed
- A terminal or command prompt
- A Java-compatible code editor or IDE

### Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/fernandooshadha/stock-management-system.git
   ```

2. Open the project folder in your Java IDE or terminal.

3. Locate the Java file containing the `main()` method.

4. Compile and run the application according to your source-file structure. For a simple project with a `Main.java` file and no package declaration:

   ```bash
   javac Main.java
   java Main
   ```

## Data Storage

The current version uses Java arrays to store supplier and stock information during program execution. The data is not permanently saved to a database, so it may be lost when the application terminates.
